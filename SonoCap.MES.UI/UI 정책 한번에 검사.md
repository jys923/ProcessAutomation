# ✅ 검사 실행 정책 (최종 확정안 - 2025-05-27 기준)

---

## 🔹 All 검사 버튼 동작 정책

| 조건 | All 버튼 동작 |
|------|----------------|
| 검사 이력 0건 | ✅ 전체 항목 검사 실행 |
| 검사 이력 일부 존재 | ✅ 미실행 항목만 검사 |
| 검사 이력 모두 존재 | ❌ All 버튼 비활성화 또는 숨김 |

- **All 버튼은 “아직 검사되지 않은 항목”만 자동으로 검사**
- **이미 검사된 항목은 All로 다시 검사되지 않음**

---

## 🔸 개별 항목 재검사 정책

- **이미 검사된 항목**을 수정하고 싶다면,
  반드시 해당 항목을 **명시적으로 선택한 뒤 개별 검사 실행**

### 재검사 허용 대상:

| 조건 | 개별 검사 가능 여부 |
|------|---------------------|
| 검사 이력 없음 | ✅ 가능 (초기 검사 포함) |
| 검사 이력 실패 | ✅ 가능 (재검사 또는 강제 통과) |
| 검사 이력 성공 | ✅ 가능 (단, 명시적 선택 필요) |

- 강제 수정 또는 재검사는 반드시 **"사용자 선택 + 명시적 실행"** 필요
- **자동 검사 흐름에서는 기존 성공/실패 항목이 변경되지 않음**

---

## 🔸 UX 설계 의도

- ✅ **실수 방지**: All 버튼으로 기존 결과를 덮어쓰지 않음
- ✅ **책임 명확**: 수정을 원할 때는 사용자가 항목을 직접 선택해야 함
- ✅ **예측 가능한 동작**: All은 "누락된 항목만", 개별은 "명시적 선택만"
- ✅ **로깅 용이**: 어떤 항목이 언제, 왜, 누가 수정했는지 추적 가능
- ✅ **단순한 UI 흐름**: All → 초기 검사용 / 개별 → 수정·재검사용

---

## 🔸 Tooltip/안내 메시지 예시

- All 버튼 hover 시:
  > "전체 검사는 아직 검사되지 않은 항목에만 적용됩니다."

- All 버튼 비활성화 시:
  > "모든 항목에 검사 이력이 존재하여 전체 검사는 실행할 수 없습니다."

- 개별 검사 버튼 안내:
  > "기존 결과를 변경하려면 항목을 선택 후 개별 검사를 실행하세요."

## ✅ 최종 요약

> **All 버튼은 아직 검사되지 않은 항목만 자동 실행하며,  
이미 검사된 항목은 반드시 사용자가 직접 선택하여 개별적으로 재검사해야 한다.**
