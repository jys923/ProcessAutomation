# ✅ 수평 선 패턴 검출 로직 정리 (GeoInspection)

---

## 1. ROI 설정

```cpp
#define ROI_X  60
#define ROI_Y  (335 - 256)
#define ROI_W  400
#define ROI_H  (NUM_SLICES * 10)
#define NUM_SLICES 4
```

- ROI: 수평 띠가 나타나는 가능성이 높은 영역
- 슬라이스: ROI를 수평으로 `NUM_SLICES` 등분한 줄
- 슬라이스당 높이 = `ROI_H / NUM_SLICES` = 10픽셀

---

## 2. 슬라이스별 계산

각 슬라이스마다:

- 평균 밝기 `sliceMean[i]`
- 분산 `sliceVar[i] = stddev^2`

전체 ROI 기준:

- 전체 평균 밝기 `meanBrightness`
- 전체 표준편차 `stdBrightness`
- 가장 밝은 슬라이스의 평균 `maxSliceMean`
- 가장 밝은 슬라이스의 분산 `maxSliceVar`
- **대비 비율** `contrastRatio`:

  \[
  \text{contrastRatio} = \frac{\text{maxSliceMean} - \text{meanBrightness}}{\max(\text{meanBrightness}, 1.0)}
  \]

---

## 3. 최종 판정 기준

| 조건 | 해석 |
|------|------|
| `contrastRatio` ≥ 0.15 **AND** `maxSliceVar` ≤ 30 | 밝고 균일한 선이 있음 → **직선 가능성 높음** |
| `contrastRatio` ≥ 0.15 **AND** `maxSliceVar` ≥ 50 | 밝은 영역은 있으나 퍼짐 → **곡선 또는 노이즈** |
| `contrastRatio` < 0.1 | 선 없음 또는 매우 흐릿함 |
| `stdBrightness` ≥ 20 | ROI 전체가 복잡함 → **노이즈 많음** 가능성 |

---

## 4. 시각화 방식

- 전체 ROI → **빨간색 사각형**
- 가장 밝은 슬라이스 → **초록색 사각형**

---

## 5. 예시 결과 (JSON)

```json
{
  "Geo": {
    "brightnessContrast": 0.21,
    "maxSliceMean": 112.82,
    "meanBrightness": 93.20,
    "stdBrightness": 24.80,
    "maxSliceVar": 12.5
  }
}
```

→ 대비 높고 분산 낮음 → **선명한 직선 존재**

---

## 6. 추가 고려사항

| 항목 | 확장 방향 |
|------|-----------|
| 슬라이스 수 | 너무 많으면 곡선도 쪼개져 의미 희석됨 → 3~6 적절 |
| 곡선 검출 | 슬라이스 분포 + 분산 조합으로 간접 판단 |
| 고급 대응 | CNN이나 패턴 템플릿 매칭 등도 가능 (후속 과제)
