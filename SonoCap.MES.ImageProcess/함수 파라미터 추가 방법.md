# 🎯 C++/CLI + C# 영상 분석 시스템: JSON 기반 설정 전달 구조

## ✅ 구조 개요

C#에서 C++/CLI의 `OpenCVWrapper` 클래스를 호출하고,  
내부에서는 Native C++ 코드로 연결되며, 설정은 JSON 문자열로 전달됨.

---

## 🧩 구성도

```text
[C#]                           [C++/CLI]                              [Native C++]
 └ SetAnalyzeConfigJson()  →  OpenCVWrapper::SetAnalyzeConfigJson()  →  ::SetAnalyzeConfigJson(json)
 └ AnalyzeFFT(...)         →  OpenCVWrapper::AnalyzeFFT(...)         →  AnalyzeFFT(..., g_config)
```

## 1. C++/CLI (OpenCVWrapper.h / .cpp)

```cpp
public ref class OpenCVWrapper
{
public:
    static void SetAnalyzeConfigJson(System::String^ json)
    {
        System::IntPtr ptr = System::Runtime::InteropServices::Marshal::StringToHGlobalAnsi(json);
        const char* nativeStr = static_cast<const char*>(ptr.ToPointer());
        ::SetAnalyzeConfigJson(nativeStr); // native C++ 함수 호출
        System::Runtime::InteropServices::Marshal::FreeHGlobal(ptr);
    }

    static void AnalyzeFFT(System::IntPtr buffer, int width, int height, System::IntPtr textBuffer);
    // 기타 함수들 ...
};
```

## 2. Native C++ (UltrasoundQualityAnalyzer.cpp 등)

```cpp
#include "json.hpp" // nlohmann::json

struct AnalyzeConfig {
    float lowFreqRadiusRatio = 0.05f;
    bool enableLog = false;

    void loadFromJson(const std::string& json) {
        try {
            auto j = nlohmann::json::parse(json);
            if (j.contains("lowFreqRadiusRatio")) lowFreqRadiusRatio = j["lowFreqRadiusRatio"];
            if (j.contains("enableLog")) enableLog = j["enableLog"];
        } catch (...) {
            std::cerr << "[SetAnalyzeConfigJson] JSON 파싱 오류" << std::endl;
        }
    }
};

static AnalyzeConfig g_config;

extern "C" __declspec(dllexport)
void SetAnalyzeConfigJson(const char* json)
{
    g_config.loadFromJson(json);
}
```

## 4. C# 사용 예시

```csharp
string jsonConfig = @"{
    ""lowFreqRadiusRatio"": 0.07,
    ""enableLog"": true
}";

OpenCVWrapper.SetAnalyzeConfigJson(jsonConfig);

// 이후 분석 호출
OpenCVWrapper.AnalyzeFFT(buffer, width, height, textBuffer);
```

## ✅ 장점 요약

- 🔐 안전한 문자열 기반 CLR ↔ native 통신
- 🔄 설정 추가 시 JSON 필드만 확장 → 유지보수 용이
- 🧩 기존 `Action<IntPtr, int, int, IntPtr>` 구조 유지
- 🔧 동적 설정 변경도 가능

## 📝 확장 팁

- `SetAnalyzeConfigJson()` 외에도 `GetAnalyzeConfigJson()`을 만들어 C#에서 현재 설정을 다시 가져올 수 있음
- 멀티스레드 환경에서는 `g_config`를 `thread_local` 또는 복제 구조로 격리 필요
